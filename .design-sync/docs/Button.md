# Button

The app's standard action. `primary` is the single solid action on a screen - one per view; everything else steps back to `ghost` (glass) or `quiet` (bare). `danger` is reserved for the one irreversible action, which is what keeps it legible as one.

Use `size="small"` only in dense rows; it restores a full touch target on coarse pointers automatically.
